SYNDFCO - ADMIN RIENG + SECURITY

1) Supabase > SQL Editor > New query
   Mở file SECURITY-SETUP.sql, copy toàn bộ > Run 1 lần.

2) Bật người chơi ẩn danh:
   Supabase > Authentication > Providers (hoặc Sign In / Providers) > Anonymous > Enable.
   Mục này bắt buộc để mỗi trình duyệt có một auth.uid riêng mà người chơi KHÔNG cần tạo tài khoản.

3) Tạo tài khoản Admin:
   Supabase > Authentication > Users > Add user / Create user.
   Tạo EMAIL + PASSWORD cho admin của khách.
   Sau khi tạo, copy UUID/User ID của tài khoản admin.

4) Cấp quyền Admin:
   SQL Editor > New query, chạy (thay UUID bên dưới):

   insert into public.admin_users (user_id)
   values ('DAN-UUID-ADMIN-VAO-DAY');

5) Test:
   - index.html = website người chơi. Không còn nút ADMIN TEST.
   - admin.html = trang quản trị riêng.
   - Chạy bằng Live Server.
   - Người chơi vào index.html, tạo chat.
   - Admin vào /admin.html, đăng nhập email/password ở bước 3.

6) Trước khi bàn giao:
   - Tạo Supabase project thuộc tài khoản khách rồi thay SUPABASE_URL + SUPABASE_PUBLISHABLE_KEY trong script.js và admin.js.
   - Không đưa database password, secret key/service_role vào frontend.

LƯU Ý VỀ DATA TEST CŨ:
Các conversation đã tạo trước khi chạy SECURITY-SETUP.sql chưa có player_user_id. Admin vẫn thấy chúng, nhưng player cũ sẽ không mở lại được. Tạo conversation mới để test security chuẩn.
